# Angular WebPlayer

Use CarCutter WebPlayer in your Angular app (Angular 19 or later)

## Usage

1. Install package: `npm install @car-cutter/angular-webplayer`
2. Import: `import { WebPlayer } from "@car-cutter/angular-webplayer"`, and add it to the `imports` of your component
3. Use: `<car-cutter-webplayer [compositionUrl]="url" />`

### Next Steps

For more customization, take a look at the **[Online Documentation](https://carcutter.github.io/cars-webplayer-js/)**
